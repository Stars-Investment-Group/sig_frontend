Je veux créer une application web professionnelle nommée **Global Macroeconomic Tracker**, conçue pour les analystes macro, traders institutionnels et gestionnaires de portefeuille.

Voici les exigences détaillées du projet :

---

📦 **Technologies à utiliser** :
- **Framework Frontend** : React.js (ou Next.js si possible)
- **UI Library** : Tailwind CSS + shadcn/ui (ou Material UI)
- **Graphiques** : Chart.js ou Recharts
- **API de données** : FRED, Eurostat, IMF, World Bank (format JSON)
- **Routing** : système de navigation par onglets/pages (`Overview`, `Trends`, `Analysis`, `Data`)
- **Gestion d'état/API** : React Query ou SWR

---

🧭 **Structure du projet** :

- `/pages/index.jsx` → **Overview** (accueil)
  - Cartes pays avec indicateurs macro (inflation, chômage, taux directeur, PIB)
  - Badge de variation YoY avec flèches rouges/vertes
  - Bloc “Economic Intelligence” avec alertes dynamiques

- `/pages/trends.jsx` → **Trends**
  - Sélecteur d’indicateurs + pays
  - Courbes temporelles (line charts) sur 12 mois ou plus
  - Analyse automatisée : tendance en hausse, plateau, baisse

- `/pages/analysis.jsx` → **Analysis**
  - Classification des régimes économiques (surchauffe, récession, etc.)
  - Graphiques de cycle macro (Yield Curve, Policy Gap, etc.)
  - Heatmap comparative entre pays

- `/pages/data.jsx` → **Data Explorer**
  - Table de données triable et exportable (CSV/XLSX)
  - Recherche d’indicateur
  - Sélection pays / période

---

🎨 **UI/UX attendue** :
- Thème sombre professionnel
- Design épuré style Bloomberg Terminal
- Navigation fluide entre les pages
- Responsive : adapté pour desktop, tablette, mobile
